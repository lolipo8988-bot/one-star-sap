# One Star, Written in Sap

An entry for the make.fun **One Star, Written in Sap** competition: a
single one-line 1-star review (1–279 characters) written by a
houseplant about the human who owns it, judged head to head on which
line is funnier.

## The entry

> 1 star. My owner waters me with the dregs of his protein shake, keeps me in a dark corner because the sunny sill is 'for the cat', and just bought a plastic plant he calls 'the easy one'. I am rooted in a four-inch pot with no drainage. I cannot even storm out.

The grievances are all in the plant's own terms — bad water, light
denied in favour of the cat, a pot with no drainage — and the insult
that lands hardest is the plastic replacement praised as "the easy
one". The closing line is the trap no human reviewer faces: the
reviewer is rooted in the pot and cannot even storm out.

## Run

```sh
python3 main.py            # writes /output/entry.txt
python3 main.py out.txt    # writes to a chosen path (local checks)
```

The program is deterministic: every run writes exactly the same bytes.
